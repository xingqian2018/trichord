## Details

### Caption Format Experiments

- Caption format experiment series. [[Doc](https://docs.google.com/document/d/12FydDwgtQKxezGSYv0kdPaMp138SeiXnabmWe4wQfnU/edit?tab=t.na6xpxqycfjc)]
  - Verified that given fixed information level, caption format doesn't matter that much in terms of generation quality.
  - Verified that matching train-time JSON caption with the same caption JSON upsampler should yield the best performance.
- Entity-based captioning design, with a series of experiments [[Doc](https://docs.google.com/document/d/1PfIQHqqoTwgL8kKS5rcChM6dLDEIYAH-hXjdY-c6fqo/edit?tab=t.yle9dbms7xdb)]
  - Verified that given similar information level, structured caption yields higher precision with more coverage.
  - Verified that the more VLM says, the lower its accuracy.
