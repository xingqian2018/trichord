## Details

### Diffusion RL on Cosmos3-Super-T2I [[Doc](#)]

- DiffusionNFT on Cosmos3-Super-T2I to confirm the algorithm works correctly on Cosmos I4 repo.
- Guildline the supporting infra: online-rollout from policy/legacy model, gateway reward model call, gradient-accumulated for effective batch size up to 1000, and a lightweight prompt-only data loader.
- Baseline config: 24 nodes, 12 rollouts/prompt (6/batch), 48 prompts/step (1152 rollout samples/step), gradient accumulation of 4, LR 3e-4.
- Result: training is stable and raises PickScore from 20.1 to 23.9, at ~100s/step including rollout, reward, backward, and update.
- Ablations:
  - rollout 24 vs. 12 (+0.16 PickScore for 2x nodes)
  - LR 3e-4 vs. 1e-4 (3e-4 converges faster to the same ceiling), one-cycle-off async (33% faster but -0.2 PickScore vs. on-policy)
  - training on upsampled JSON prompts (more visually detailed output but -1.7 PickScore.
- Applied the rule-based OCR reward on Cosmos3-Super-T2I, successfully boosting OCR quality:
  - GNED: 0.8088 → **0.9143** (+11%)
  - PNED: 0.8908 → **0.9613** (+7%)
- SIFR paper and other experimental DiffusionRL tries. (No longer the focus)

### High-Quality Image Midtrain Data Captioning

- 11M captioned high-quality images for the midtraining purpose.
- 350K getty image download and caption for ablation study.

### Cosmos3.5 Building Image Capabilities Agentic Trace [[Doc](#)]

- Designed the general agentic harness: a loop that drives a teacher agent through a "T2I tool environment" to produce a final result with critic justification and iterative refinement.
- Scoped four target agentic capabilities: general T2I refinement (prompt upsampler / T2I / T2I-edit tools with critic-gated regeneration), OCR text-layout/poster generation (HTML/XML-driven layout with T2I as an asset tool), HTML webpage generation (full interactive UI with buttons/elements), and diagram/chart generation (matplotlib, Chrome rendering, LaTeX, PowerPoint as tools).
- Verify with the team about agentic trace output schema (tool-declare / thinking-effort / system / user / etc.) and some convertable on-disk sample layout (chat.json, etc.).
- Taskflow harness v0, generated a first batch of 20K samples, each with a thinking trace, generated image, and 20+ visual critic scores.

### Dense Pretraining LM [[Doc](#)]

- Reproduced the rung m0 & m1 tpp20&tpp200 result: KD loss 1.5805 vs. baseline 1.614 (−0.034 nats), confirming the KL-distillation can give consistent gains.
- Investigating other LM accesories such as cross-tokenziation and MuonH.
