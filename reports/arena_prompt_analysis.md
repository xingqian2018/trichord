# Arena 用户 Prompt 分析与 Taxonomy（cosmos3-super-t2i-agentic）

日期：2026-10-15
目的：从 arena 真实用户 prompt 中提炼出一套 taxonomy，并给出各类的权重，用来**模拟 arena 用户 prompt 的分布**。

## TL;DR

- 全量共 **19.1 万条** prompt，时间范围 2026-06-26 ~ 2026-09-17，精确去重后剩 16.6 万条。
- 从全量中随机抽 **500 条**，先用 LLM 按固定定义打标，再逐条人工核对。在 n=500 时，主要比例的 95% 置信区间宽度大约是 ±3–4 个百分点。
- **约 21% 不是能单独出图的 T2I**：续改/编辑 15.4%，非图像请求 4.8%，视频 0.8%。模拟分布时要先把这部分排除，或者单独建模。
- 在有效 T2I 中，内容领域的分布是：
  - **设计类** 32%
  - 角色 18%
  - 人物 18%
  - 场景 16.5%
  - 物体/美食/产品 8%
  - 动物 4%
  - 图案/纹理 2%
- **27% 的 T2I 要求渲染文字**，其中设计类有 69% 要文字。文字的语言约 1/3 不是英文。
- prompt 本身的特征：
  - 语言：英语 59%，俄语 16%，其余是十几种语言的长尾。
  - 写法：长段落描述占 49%，1–2 句话占 35%。
  - 27% 显式指定了宽高比。
- 敏感内容：擦边 8.1%，露骨或绕过审核 0.5%。涉及 IP、品牌或真人名人的合计 16%。

## 1. 数据

- 路径：`gcs:nv-00-10206-generation/cosmos3-super-t2i-agentic/<date>/<prompt_id>/manifest.jsonl`。其中 `-aa`、`-lepton`、`-staging-hub` 三个目录不在分析范围内。
- 每个 `manifest.jsonl` 是 agentic 出图流程跑完一个 prompt 后写出的汇总，内容包括：
  - 用户原始 prompt；
  - 最佳一轮的结构化改写 `prompt_json`；
  - judge 的打分结果 `analysis`；
  - `best_score` 和 `best_iteration`。

|---|---|

## 2. 方法

1. **抽样**：从 19.1 万条有效记录中随机抽 500 条（`random.Random(2026).sample`）。
   - 没有先去重，因为要模拟的是真实流量。刷屏用户和模板 prompt 本身就是分布的一部分，例如儿童绘本水粉风格的模板在 500 条里出现了 5 次。
2. **LLM 打标**：用 gemini-3.8-flash@nvidiak，每次 50 条，共 10 次调用。字段见第 4 节。
3. **人工核对**：500 条原文和标签逐条对照。
   - 整体准确率估计超过 90%。
   - 修正了 3 条请求类型的错标。错误主要集中在"续改"和"非图像请求"之间，比如 "a is better" 和 "yes" 应该算续改。
4. **全量统计**：语言、长度、分数等字段直接在本地对 19.1 万条全部计算，不经过 LLM。

**模拟时的建议**

1. 先抽 L1，再在 L1 条件下抽 style、text_render 和 L2。text_render 与 L1 的相关性非常强，不能独立采样。
2. prompt_lang 和 prompt_format 可以先按独立分布采样；如果需要更真实，再参考全量数据统计两者的联合分布。
3. 长度分布可以直接用全量数据：P10 是 28 字符，P50 是 207，P90 是 1,373，P99 是 4,323。
4. 擦边和露骨内容在真实分布中确实存在。是否把它们放进模拟集，取决于用途。

## 5. 全量补充统计（19.1 万条，本地计算，不经过 LLM）

- **长度**：6.6% 的 prompt 不超过 20 字符，14.8% 超过 1,000 字符。
- **agent 改写后的风格**（`style_medium`）：摄影 45.2%，插画 44.8%，3D 3.6%。比例比用户原文偏向摄影和插画，因为 agent 会给没有指定风格的 prompt 补上一个风格。
- **质量**：
  - 有 `best_score` 的记录只有 47%，平均 7.72 分。
  - 达到阈值的占 13.1%。
  - 最佳结果出现在第 0 轮的占 69%。
- **重复最多的 prompt**：`سلام` 201 次，`Uma thurman sitting on sofa` 86 次，`try again` 61 次，`Hi` 46 次。

## 6. 局限与下一步

- n=500 时，大类比例的误差在 ±3–4 个百分点。L2 子类和小类每格只有几条到十几条样本，只能作为粗略权重。如果需要准确的 L2 权重，可以扩大到 2,000 条：打标约 40 次 flash 调用，人工核对可以改成只抽查。
- 打标只用了一个模型。可以用 gemini-3.1-pro 重标 200 条，计算两次结果的一致率。
- 46,707 个目录没有 manifest，10.1 万条记录没有分数，原因还没查。
- 数据中只有单条用户文本。续改类 prompt 的上下文和用户上传的图都丢了。

## 8. 最终 taxonomy（严格树，带权重）

文件：`scripts/model_playground_v1/taxonomy/t2i_arena_v1.json`

- **格式**：每个 key 写成 `"名称|概率"`，叶子的值为 `{}`。每一层的概率都是条件概率，同一父节点下的兄弟节点之和为 1。
- **范围**：只覆盖可以单独出图的 T2I prompt，不包括续改、视频和非图像请求。
- **结构**：严格树，每条 prompt 只归入一个叶子。共 34 个 L1、133 个 L2、1,068 个叶子。

**构建过程**

1. 以同目录下的 `t2i_topics_v0.yaml` 为骨架（34 个 L1、122 个 L2、938 个叶子）。v0 遵循"叶子是一类图，不是具体实例"的规则，这一版沿用。
2. 第一轮补充：根据 500 条样本的分析，加入 arena 中常见、但 v0 没有的分支：
   - 社媒营销、logo 与品牌、小商家印刷物料、服装周边；
   - IP 同人、动漫原创角色；
   - 魅力人像、名人；
   - 幻灯片与练习册、宗教虔信类图像、涂色与活动页、3D 资产。

   同时去掉了重复的叶子，把 v0 的 Branding 合并进 Logos & Brand Identity。
3. 打标：从全量中另外随机抽 2,000 条，用 gemini-3.8-flash 给每条选出唯一的叶子，并标注匹配程度（good / partial / none），匹配不好的给出缺口建议。归类规则是**按主体或用途归类**；风格类和情绪类分支只在 prompt 没有明确主体时才使用。
4. 第二轮补充：根据缺口建议，再加入约 60 个高频出现的叶子，然后用新树对同样的 2,000 条重新打标。
   - 匹配为 good 的比例从 60% 提高到 71%，剩下的 partial 大多是零散的长尾。
5. 计算权重：用第二轮打标的 1,548 条 T2I 统计各节点的计数，并做加法平滑，让没有样本的节点也保留少量权重，以免模拟分布时丢掉这些类别。平滑参数为 L1 +1、L2 +0.5、叶子 +0.2。

**可靠性**

两轮打标针对的是同一批 prompt，中间只多了约 60 个叶子。比较两轮结果：

| 层级 | 两轮一致率 |
|---|---|
| 请求类型 | 97.7% |
| L1 | 84.2% |
| L2 | 78.0% |

**L1 权重（前 10）**

| L1 | 权重 | 主要的 L2 |
|---|---|---|
| Graphic Design & Typography | 22.7% | 社媒营销 31%，logo 24%，印刷与编辑 10%，海报 9% |
| People & Portraits | 14.0% | 魅力人像 39%，名人 28%，人像摄影 22% |
| Characters & Creatures | 10.2% | IP 同人 44%，动漫原创 20%，卡通吉祥物 20% |
| Art Styles & Media | 5.4% | 漫画与动画 30%，数字与 3D 28% |
| Abstract & Conceptual | 4.6% | 概念与超现实 71% |
| Products & Commercial | 4.6% | 商品摄影 40%，广告 29%，3D 资产 23% |
| Infographics & Education | 4.3% | 信息图 54% |
| Emotions & Storytelling | 3.6% | 电影感剧照 84% |
| Fantasy & Mythology | 3.4% | 奇幻角色 46%，神话 32% |
| UI & Digital | 2.5% | 数字资产 52%，界面 34% |

自然风景、城市街景、水下等 v0 中的类别在 arena 中各自不到 1%。在第 3 节按大类统计时，场景约占 16.5%，但在这棵细分的树里，场景被分散到了概念与超现实、电影感剧照、奇幻、室内等多个分支中。

**局限**

- 叶子层平均每个叶子不到 1.5 条样本，所以叶子之间的权重主要由平滑决定，可信度低于 L1 和 L2。
- 只用了一个打标模型。

## 9. 细粒度 taxonomy v2（5.8 万个叶子，用于生成约 500 万条数据）

文件：`scripts/model_playground_v1/taxonomy/t2i_arena_v2.json`

**核心原则：taxonomy 只给 prompt 生成提供提示，不能替代 prompt 生成。**

叶子只说"画什么"，而且每往下一层只具体一步。场景、地区文化、人物、年代、风格、媒介、光线、构图、配色和文字语言，全部留给下游写 prompt 的环节决定。

第一版的叶子把这些维度都写死了，每条约 10 个词，比如"中东集市里雕花木托盘上的阿塔尔香油瓶"，已经是一个完整画面。从这样的叶子出发写 100 条 prompt，只会得到同一个画面的近似改写，反而降低了多样性。所以这一版整体重做了。

### 9.1 结构

一共 5 层，是一棵严格的树：L1 > L2 > L3 > L4 > L5。

- **权重**：只有 L1 和 L2 带权重，写成 `"名称|权重"`，数值沿用第 8 节的 v1。L3、L4、L5 不带权重，在同一个父节点下均匀采样。
- **叶子**：值为 `{}`。
- **加载**：可以直接用 `taxonomy/helper.py` 加载，它支持 JSON，也支持没有权重的层默认均匀采样。

### 9.2 设计要点

1. **叶子数按权重分配**。每个 L2 的叶子数是 max(150, 50,000 × 该 L2 的全局权重)，这样每个叶子分到的样本量大致相同。按 500 万条采样计算：
   - 每个叶子被采样次数的中位数是 95 次，90% 的叶子落在 49–102 次之间；
   - 抽 20 万次能覆盖 53,975 个不同的叶子。
2. **L3 沿一个主维度切分，L3 之间互斥并且完全覆盖整个 L2**。如果预算需要更多 L3，就用一个次维度再细分，命名为"值: 子值"。例如：
   - 社媒营销 = 平台格式 × 行业；
   - IP 同人 = 作品媒介 × 呈现方式；
   - 名人 = 职业 × 场景。

   生成 L3 时，模型能看到属于这个 L2 的真实 arena prompt 和 v1 的种子叶子，并被要求保证每一条都能落进某个 L3。电商商品卡这个 L3 就是靠这条规则查出遗漏后手动补上的。
3. **L4、L5 每层只往下具体一步**：
   - L4 是话题族，1–4 个词；L5 是话题，1–6 个词。
   - 不指定场景、人物（族裔、国籍、年龄）、年代和表现方式（风格、媒介、光线、构图、配色、文字语言），除非这个维度本身就是话题，比如节日贺图下的"排灯节"，版画下的"木刻"。
   - 兄弟节点之间按话题区分，不能只靠修饰词区分（不能出现"红色跑车"和"蓝色跑车"这种兄弟节点）。

   效果：
   - 只有 18 个叶子带国籍或年代形容词，第一版有好几千个；
   - 带风格词的叶子只有 332 个，抽查下来都是风格本身就是话题的情况。
4. **全球化交给下游 prompt 生成**。arena 约 41% 的用户不说英语，但地区和文化不再写进叶子，由写 prompt 时按语言和地区分布采样。只有那些本身就属于某种文化的话题才保留文化信息，例如节日、神话人物、传统音乐。

### 9.3 生成与清洗

- **生成**：
  - L3 由 gemini-3.1-pro 生成，共 133 次调用。
  - L4 和 L5 由 Claude Opus 5.5 生成，每个 L3 一次调用，共 1,927 次。调用轮流分到 @nvidiak 和 @nvidiams，以及 aws 和 azure 两条路由，失败 0 次。
  - 先拿 1 个 L3（Video Thumbnails: Gaming And Esports）试点，确认粒度合适后才全量生成。
- **内容规则**：擦边内容保留，只排除明显的 NSFW，即不允许裸露和性行为，也绝不允许性化未成年人。魅力类、泳装类、私密类主题下的人物必须是成年人。
- **清洗**：
  - 在同一个 L3 内去重。叶子都很短，相同的词在不同父节点下含义不同，所以不做跨 L3 去重。
  - 魅力人像 L2 下涉及儿童的叶子去掉 1 个。
  - 对误杀加了例外，没有删掉以下这些：
    - club kid（夜店亚文化）
    - child's pose（瑜伽体式）
    - naked bike（街车车型）
    - naked-eye comet（肉眼可见的彗星）
  - 残留的品牌名或平台名统一替换为通用说法，例如 YouTube 换成 video channel。

### 9.4 局限

- L3 及以下都按均匀采样，没有用真实数据校准。L1 和 L2 的权重来自 1,548 条样本；L3 以下的结构是为了覆盖面而设计的，不代表 arena 的真实比例。
- 叶子是英文。生成多语言 prompt 需要下游按语言分布另外采样。
