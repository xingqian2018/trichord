Cosmos3 / 3.5 生成器实验汇总

把这个实验表 34 个 tab 的内容按主题整理：Cosmos3.5 的 30B-A3B MoE 训练配方、优化器和 MoE router、架构与条件注入、早期超参扫描、推理设置，以及 RL 和 Edge 小模型。数字照抄原表，除非另有说明，加粗表示该组里最好的一项。

结论速览 3.5 MoE 配方 优化器 Router 稳定性 架构与条件 早期超参 推理设置 RL Edge 2B 未完成

结论速览

  • shift 选 1.5 / 3.5 / 6（256p / 480p / 720p）：四组里最好，UGB 0.684，基线 1 / 3 / 5 是 0.650，AutoHUE 0.675 对 0.607。跟现在 3.5 v2 pretrain 配置的 shift 一致。
  • LR 1e-4：LR × global batch 扫描里，4 种 global batch 下都是 1e-4 最好；3e-4 和 1e-5 都明显掉分。
  • token 总量固定时，小 batch、多步数更好：同样约 568B token，64 节点 60k 步 UGB 0.608，256 节点 7.5k 步只有 0.468。
  • 图像数据占比越高越好，视频指标也一起涨：动作固定 10%，图像占比从 5% 提到 40%，UGB 从 0.369 涨到 0.707，PAI T2V 从 67.8 涨到 74.2。
  • 三阶段训练按 33 / 33 / 33 分配最好，只跑 stage 3 最差（480p UGB 0.813 对 0.770）。
  • DION2 明显好于 AdamW：2B dense 的 PAI T2V 从 68.1 涨到 74.4，30B MoE 从 76.1 涨到 78.3。但 lr_scale 超过 1 后参数范数一直涨，MoE 在 lr_scale 2 时崩到 61.7。
  • Router 改动主要提升健康度，跑分基本不变：长训练后各方案 PAI T2V 都在 77.9–78.8，有效专家数从 8.5 提到 10.9。dot-product + sigmoid router 把 routing 健康度从约 0.002 提到约 0.13。
  • AdaLN（shared）在 8B dense 上 +2.5 PAI T2V（75.9 → 78.4）；MoE 版本还在跑。加 modality embedding 反而掉分。

Cosmos3.5 MoE 配方（30B-A3B）

tab：MoE recipe ablations · 基线 run cosmos3p5_ga_60bm30b_lrdecaystudy_lr_1e4_warmup_linear_100k_round2

这一节所有实验都在 30B-A3B MoE（cosmos3p5_ga_60bm30b，即 3.5 Super 的规模）上做。这一页的指标：UGB 是 0–1 分制，PAI 是 T2V / I2V 的 overall，AutoHUE 只看 I2V。大多数 run 训练 100k 步。

shift 扫描（UGB）

分辨率依次为 256p / 480p / 720p，悬停可看 PAI 和 AutoHUE。

token 总量固定（约 568B），改变 batch 和步数（UGB）

每条 74K token，2 个 seed。batch 越大、步数越少，分数越低。

LR × global batch（UGB，100k 步，WSD 5% 冷却）

每格的 global batch = 节点数 × 每节点序列长度。每一列里 1e-4 都最好；batch 翻倍一般也涨分，但训练看到的 token 也同步翻倍。

模态比例：动作固定 10%，横轴是图像占比

图像占比 i 越高，三个指标都在涨，i40 / v50 / a10 最好。另一组固定图像:视频 = 1:4、改变动作占比：动作从 25% 降到 5%，UGB 从 0.547 涨到 0.595，PAI T2V 从 71.0 涨到 72.7。

表里的解释：Muon 类优化器把每步更新的大小归一化掉，每一步往 2D 权重里注入固定量的范数，只有 weight decay 能把它去掉。lr_scale 调大但 weight decay 不变，平衡时的范数就会一直涨；大规模训练时 lr_scale 不宜超过 1。

  • 训练 loss（2B，T2I，70k 步）：AdamW 1.591；Muon lr_scale 1 是 1.503；DION2 lr_scale 2 是 1.492。每步耗时：AdamW 0.531 s，DION2 约 0.585 s，Muon 约 0.9 s；DION2 比 Muon 快很多，只比 AdamW 慢约 10%。
  • 2B dense 大规模（1024 卡）：DION2 每步 1.56 s，AdamW 2.67 s；30k 步时 loss 1.410（DION2，lr_scale 2）对 1.613（AdamW）。
  • 30B-A3B 的 DION2：lr_scale 1 和 2 时 loss 飙到 13.3。表里怀疑 Batched-MM 没被 DION2 当成 linear 层，这是个潜在 bug。
  • router 用 Manifold Muon：momentum 版本直接崩（UGB 0.245）；gradient 版本 + 1D weight decay 也比基线低 0.03–0.07 UGB，所以没采用。

  • FPS 控制：Cosmos3 Nano 上，文本 + 3D MRoPE 组合分最高（9.81；不加控制 8.51）。但更早的 2B 实验里，加 RoPE FPS 后视频质量分从约 11.4 掉到 3–5，这组数字没有后续说明。
  • NTK / 位置编码缩放（2B）：现有的仅时间维 index scaling 平均质量最高（全 fps 平均 7.775）；改成时空 index scaling 或 NTK 缩放，在 5 fps 和 720p 上会掉分。base theta 取 5M 时 dynamic degree 更高。

RL（DDRL）

tab：Cosmos3 Generator RL · Reproducing Cosmos2.5 DDRL

  • Cosmos3 EA1.01 8B 上跑 DDRL：LR 1e-5，64 步，overall 从 1.845 降到 1.748（VQ 0.308 → 0.267，MQ −0.155 → −0.206，TA 基本不变）。目前只有这一组，RL 后变差。
