结论

  • KD 在所有 rung、所有验证集、所有 α 上都比 CE 低（108 个格子全部为负）。
  • 增益随规模变大：overall_tw 上 KD 降低的 loss 为 0.041 → 0.045 → 0.049 → 0.052（q0 → q3）。
  • 等效规模：KD 模型的 loss 相当于 1.19 → 1.25 → 1.31 倍激活参数的 CE 模型（在 CE 的 loss–log N 曲线上插值），倍数也在随规模变大。
  • 增益最大的是 uncheatable / codefresh，最小的是 val_v2 和 private_internal；private_internal 是训练语料之外的私有集，KD 在上面同样稳定变好。
  • α 0.7 / 0.8 / 0.9 基本分不开（最大差 0.004），选 α 不影响结论。
  • 对比优化器（都是 CE）：MuonH 相对 AdamW 降低的 overall_tw loss 随规模缩小（0.079 → 0.039 → 0.026 → 0.019 (q0 → q3)），而 KD 的增益随规模变大——KD 带来的收益比换优化器更能保持到大模型。
  • 各种 KD loss（同一 α 0.8、MuonH）：采样 tail 的变体一直比 B64 好，但领先随规模缩小（overall_tw，q0 → q2：S64Y -0.0059 → -0.0045 → -0.0029；S64 -0.0023 → -0.0052 → -0.0035；S128 -0.0023 → -0.0040 → -0.0031）；bucket 类变体 ≈ 0（B64Y -0.0002 → -0.0017 → +0.0007；B128 -0.0008 → -0.0018 → +0.0001）。
  • MuonH 学习率：最优倍数 q0: 1.4× (-0.0023)（括号内 = 相对 1× 的差）；HyperP 规则给出的 LR 接近最优。
