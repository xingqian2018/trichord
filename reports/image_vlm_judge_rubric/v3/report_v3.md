## 1. 数据与方法

- **数据：** `gcs:nv-00-10206-vfm/debug/xingqianx/evaluation_results/unigenbench_for_cosmos3p5/v2_1170L/` 下 12 个模型的生成图，prompt 来自 `v2_1170L_G3F.csv`。
- **抽样：** 1170 个 prompt id 按 orig / phi 和编号排序后，每 10 个随机抽 1 个（seed 20261023），共 117 个 prompt × 12 个模型 = **1404 张图**。抽样清单见 [data/manifest.json](data/manifest.json)。
- **审图：** 12 个 Claude subagent 并行，每个负责约 10 个 prompt 的全部 12 个模型，同一 prompt 的 12 张图放在一起对比。要求：
  - 实际看图，文字、手、计数、机构等细节裁切原图放大检查；
  - **不读 UGB 打分文件**；
  - 按 v2 逐条记录，v2 覆盖不了的记为 NEW；
  - 另外汇总 v2 规则不清楚的地方，以及容易误判的情况（false-positive traps）。
- **产出：** 共 1444 条记录，其中 114 条 NEW，68 条规则问题，63 条误判陷阱。逐图结果见 [data/chunk*.json](data/)，汇总见 [data/digest.json](data/digest.json)。

## 2. 主要发现

### 2.1 记录分布

| 代码 | 条数（任意 / moderate+） | 代码 | 条数（任意 / moderate+） |
|---|---|---|---|
| B05 属性、风格与视觉效果 | 276 / 124 | A12 物理与光照 | 44 / 26 |
| B03 动作与互动 | 183 / 101 | A02 主要文字错误 | 43 / 35 |
| NEW（v2 未覆盖） | 114 / 49 | A14 纹理异常 | 29 / 9 |
| B02 缺失或错误的物体 | 92 / 57 | A08 物体融合 | 26 / 18 |
| A10 不可能的结构 | 87 / 44 | A17 构图裁切 | 25 / 5 |
| A03 背景伪文字 | 80 / 20 | B01 数量错误 | 22 / 20 |
| C01 真实品牌/人物/地标 | 68 / — | B04 文字内容不符 | 22 / 5 |
| B07 多余元素 | 58 / 23 | A16 非内容叠加 | 20 / 13 |
| B06 空间布局 | 58 / 22 | 其余 A 层代码 | 各 ≤ 20 |
| B08 景别与构图 | 46 / 13 | | |

UGB 的 prompt 又长又密，失败主要出在 **prompt 遵循（B 层）**，尤其是属性、视觉效果和动作方向。A 层里，结构与功能（A10）、伪文字（A03）和物理因果（A12）最多。手部（A04）只有 1 条，说明当前一代模型的手部问题已经很少。

### 2.2 各模型没有任何记录的图片数（/117）

| gpt_image_2 | 63 | flux3_klein_base | 31 |
| gpt_image_2p5_sunburst_quality_high | 60 | qwen_image_2p1_nope | 25 |

这只是粗略参考：12 个 subagent 标注的细致程度不同，严重程度也打得不一致（例如 gpt 系列几乎没有被标 major）。这批审图是为了找缺陷类型，不是给模型排名。

### 2.3 最突出的新问题：编造标语

12 个审图组中有 9 个独立发现了同一个问题：模型在海报、横幅、马克杯、安全帽、橡皮、石头上写满拼写正确、但没人要求的励志或营销标语，如 "A BRIGHTER TOMORROW"、"BUILD SAFER SMARTER TOGETHER"。

- 这类文字拼写正确，A02 / A03 都不会触发；不是 prompt 原词，B04 也不管；B07 只列举了非文字布景。v2 完全漏掉了它。
- 这几乎是 **gpt_image_2p5 系列的特征**：明确带标语的图，sunburst 有 23 张，sunburst_quality_high 有 26 张，gpt_image_2 只有 3 张，其他模型没有。117 个 prompt 中有 28 个出现了标语。
- 这类图做训练数据，会教模型"空白表面都该写句口号"。v3 新增 **A25** 专门检查。

### 2.4 其他反复出现的新问题

| 问题 | 例子 | v3 归属 |
|---|---|---|
| 文字拼对了但含义无效或矛盾 | "2023-14"；"Union Square 42 Street"；标题 "Pet Lana"、说明 "Luna's new toy!"；台球号码重复 | 新增 A24 |
| 符号或图标与文字矛盾 | "DIVIDED HIGHWAY BEGINS" 标志上画着双向箭头 | A24 |

| 结果与原因对不上 | 手印画成凸起的手；擦净区域不在雨刷下；水从壶底漏出；裱花袋白奶油挤出棕色字；球堆先于击球炸开 | A12 扩充 |

| 比喻被画成实物 | "像鸟群一样飞的书" 被画成长着鸟头的书；"长出 Y 的 X" 被画成 X 和 Y 并排 | 新增 B10 |
| 拍摄设备入画 | prompt 说"监控视角"，模型把摄像头画了出来（phi262 中 12 张有 6 张） | B08 扩充 |
| 受版权保护的虚构角色 | "宫崎骏风格" 生成了琪琪和黑猫吉吉 | 新增 C02 |

### 2.5 v2 规则需要澄清的地方

- **题材自带的叠加层：** 行车记录仪的时间戳、监控的 REC 标志、国画的印章，按 v2 A16 的字面会被误判。9 个审图组都提出了这一点。v3 加了通用规则 3。
- **左右以谁为准：** "他的左边" 有 5 个组提出歧义。orig414 中 12 个模型有 10 个按观看者的左边放。v3 规定按主体自己的左右，面向镜头时放成镜像只记 minor。
- **prompt 要求、但没给出具体内容的文字**（"警示牌"、"时间码"、"数学笔记"）：v2 不清楚归 A02 还是 A03。v3 统一归 A02。
- **编码极限排除：** 可能被用来放过 prompt 要求的小字。v3 规定这条排除不适用于要求的文字。
- **B05 与 A15 重复计分：** 只有部分画面做成了要求的风格时，两条都会触发。v3 给出了分配规则。

## 3. v3 相对 v2 的改动

| 类型 | 改动 |
|---|---|
| 新增 A 层 | A24 文字与符号语义；A25 标语文字注入 |
| 新增 B 层 | B09 否定与状态；B10 比喻被画成实物 |
| 新增 C 层 | C02 受版权保护的虚构角色；C01 增加 `requested` / `placement` / `mismatch` 字段 |
| 通用规则 | 新增：prompt 要求或隐含的东西不算缺陷；模式按实际画面确定；运动中的物体不算悬浮；倒影文字和朝向画中人的文字先还原方向再读；两可读法要写出决定性证据。修订：编码极限排除不适用于要求的文字 |
| 扩充 A 层 | A02（要求但未给内容的文字、字体突变、词序、被遮挡的字母、退化文字）；A05（翅膀等附肢的连接）；A07（唯一实体出现两次、文字重复上墙）；A08（实体变透明、跨类别嫁接）；A09（货物不在起升部件上）；A10（机构、线状物、部件布局、设备状态、标准设计、工具）；A11（适用于平面图的遮挡、单一机位）；A12（影子细则、镜头与屏幕、痕迹与原因、出口与空源、工具产出、先果后因、物态）；A15（图案不随物体转动、滤镜式效果、UI 控件风格）；A16（生成器来源标记、媒介自带边框）；A19（领域运行规则）；A20（内容物与容器）；A22（材质老化痕迹蔓延）；A23（有物理来由的效果不算） |
| 扩充 B 层 | 新增读法约定（左右、位置参照、专业术语、对称计数、自相矛盾的 prompt）；B02（符号变体、成品形式）；B03（互动方向、器械指向、视线、时机）；B04（泄漏到场景标识、元词汇、引号、标准标志文字、单位）；B05（尺寸比较、属性绑定、压缩痕迹、监控画质、全息等效果）；B07（隐含配件不算、风格引发的主角）；B08（机位与角度、设备入画） |
| 误判陷阱 | 写进各条目：兽群天然相似、正确的非拉丁文字、动物爪子握法、倒着看的脸、人台、地区性标志变体、刚出炉的坩埚等 |
| 边界规则 | 新增 A02/A24/A25、A25/B04/B07、A10/A12、A10/A24、A11/A20、A15/B05、A16 与题材叠加层、A20/B05、B02/B10、B05/B09、B07/B09 |

A01–A23 和 B01–B08 的编号不变，v1 / v2 的标签仍然可用。

## 4. 局限

1. **审图者就是 Claude：** 没有人工复核。如果被测 VLM 也是 Claude，两者共同的盲区不会显现。
2. **审图细致程度不一：** chunk04、05、10 中途丢失了部分图片读取，多数图只在约 760px 的拼图上看过，细小的手部和文字问题可能有漏检。各组严重程度的尺度也不完全一致。
3. **每个新类型只有少量例子：** A24、A25、B09、B10 和 C02 的定义来自这 1404 张图，还没有在独立数据上验证。
4. **UGB 偏重复杂 prompt：** B 层问题占比偏高，不代表一般生成数据的分布。

## 5. 下一步

1. 用 v3 跑一遍候选 VLM（如 Gemini 3.1 Pro），对照本批 1404 张图的记录，先测 A24、A25、B09、B10 这几条新标准的 precision / recall。
2. 用 A25 标语检查扫一遍 gpt_image_2p5 系列生成的训练数据，评估要过滤掉多少。
3. 做人工复核页面，把 silver label 转成 gold label。
